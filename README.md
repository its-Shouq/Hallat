Hallat – Tourist Guide Mobile Application
Hallat is a mobile tourist guide application built to help users explore destinations, plan trips, and access travel information in one place. The project was developed as a semester-long Software Engineering course project, following the Agile/Scrum methodology across two academic semesters.
📱 Overview
Hallat was developed by a 6-member team over 7 Agile sprints, covering the full software development lifecycle — from requirements gathering and system design to implementation, testing, and deployment.
✨ Features
User authentication with Two-Factor Authentication (2FA) for enhanced security
Tourist destination browsing and trip planning
Firebase-backed real-time data storage
Secure and reliable backend integration
🏗️ Architecture
The system follows the MVC (Model-View-Controller) architectural pattern to ensure a clean separation of concerns and maintainable codebase.
